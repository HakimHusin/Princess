# My Beautiful Princess Mai Sarah ♡

A romantic, cinematic birthday website with an interactive countdown, photo gallery, letter, gift messages, matching game, starfield, finale animation and optional music.

## Open it
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension.

## Add your photos
Put four photos in `assets/images/` named exactly:
- `memory-1.jpg`
- `memory-2.jpg`
- `memory-3.jpg`
- `memory-4.jpg`

## Add your song
Put an audio file you have permission to use at `assets/music/your-song.mp3`. Music is not autoplayed; she can switch it on herself.

## Personalise the letter and messages
Edit the paragraphs in `index.html` inside `id="letterCard"`. Gift messages are in the `wishes` array in `js/main.js`.

## Birthday
The displayed birthday is 31 October 2002. The live countdown targets 31 October each year, and changes to a birthday greeting after the day begins.

## Publish for free
You can use GitHub Pages: create a repository, upload the contents of this folder to its root, then go to **Settings → Pages → Deploy from a branch → main → /(root)**. Use the published link to test on your phone before sharing it.

## Privacy
This is a static website. If you publish it publicly, anyone with the link may be able to view the photos and letter. Do not include anything you want to keep private.
